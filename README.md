# Читальня «Містка»

Скіли для Claude Code, методики й сирі матеріали архівного пошуку по українських селах. Напрацьовано в роботі над сайтом «[Місток](https://mistok.wiki)»

Тут немає теорії. Кожне правило в цих файлах або коштувало прогону, або виміряне числами, і число стоїть поруч із правилом.

## Що є зараз

| Скіл | Про що |
|---|---|
| [`skills/metryky`](skills/metryky/SKILL.md) | Метричні книги й акти ЗАГС: де взяти справу, як прочитати аркуш, як записати прочитане і чого не робити |
| [`skills/zvirka`](skills/zvirka/SKILL.md) | Звірка написаного проти джерел: чи джерело каже саме це, чи виноска стоїть на потрібному реченні, як поміряти власний текст числом |
| [`skills/presa`](skills/presa/SKILL.md) | Стара періодика: ключі пошуку по словоформах і дореформеній орфографії, вирізки замість шпальт, чотири тихі поломки OCR |
| [`skills/rozvidka`](skills/rozvidka/SKILL.md) | Розвідка кількома агентами: ексклюзивні зони джерел, друга вісь ракурсів, стелі викликів і куди насправді згорає бюджет |

## Приклад

[`examples/posimeinyi-spysok`](examples/posimeinyi-spysok/) - один аркуш, прочитаний за цим скілом: ось [фото](examples/posimeinyi-spysok/skan.jpeg), ось [що вийшло](examples/posimeinyi-spysok/prochytannia.md). Замовлення було «прочитай метрику», а перше, що дав прохід, - це не метрична книга, а посімейний список ревізького типу.

Окремо варто прочитати [`skills/metryky/references/htr.md`](skills/metryky/references/htr.md), навіть якщо метрики вас не цікавлять: це числа про те, чому автоматичне читання рукопису поки що не працює, і чому мовна модель, дивлячись на нерозбірливе, впевнено видає правдоподібне прізвище.

## Як поставити

```bash
git clone https://github.com/OuFinx/mistok-chytalnia.git
ln -s "$PWD/mistok-chytalnia/skills/metryky" ~/.claude/skills/metryky
```

Символьне посилання зручніше за копію: `git pull` оновлює скіл на місці.

Далі скіл підхопиться сам, коли ви попросите прочитати скан метрики. Викликати напряму - `/metryky`.

## Це не лише для Claude Code

Скіл це markdown, а не код. Порядок роботи, пастки й числа з нього однаково читаються людиною й однаково кладуться в будь-який інший інструмент. Команди в текстах загальні (`pdftotext`, `pdfimages`, `pdftoppm`), нічого ставити не треба.

## Ліцензія

Вільна. Беріть, копіюйте, переробляйте під себе, вставляйте у свої скіли й проєкти, робіть що завгодно - питати дозволу не треба.

Єдине прохання, і воно не юридичне: згадуйте час від часу «[Місток](https://mistok.wiki)» :)
