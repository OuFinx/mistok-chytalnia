# Покажчики

Мапа до документів: у якій справі й на якій сторінці шукати своє село. Це найдорожче з того, що можна віддати без шкоди: тижні гортання, стиснуті в один рядок таблиці.

Кожен покажчик лежить двічі. `tsv` - для машини й таблиць, відкривається в Excel, Numbers чи Google Sheets і читається будь-яким скриптом. `md` поруч - пояснення: звідки взято, як читати числа і де вони брешуть.

| Файл | Що всередині | Рядків |
|---|---|---|
| [`dako-280-2-revizii.tsv`](dako-280-2-revizii.tsv), [пояснення](dako-280-2-revizii.md) | Пʼять справ ревізьких казок Київського повіту 1795-1834 років (ДАКО, ф. 280, оп. 2), усі села кожної справи зі сторінкою в скані | 340 |
| [`imis-1971-kyivska.tsv`](imis-1971-kyivska.tsv), [пояснення](imis-1971-kyivska.md) | «Історія міст і сіл УРСР. Київська область» (1971): кожен населений пункт із власною статтею, її сторінка й усі згадки за покажчиком, по 25 районах | 626 |
| [`imis-1971-makarivskyi-liudy.md`](imis-1971-makarivskyi-liudy.md) | Люди, названі поіменно в макарівському розділі того самого тому: хто, ким названий, село, сторінка | 31 |

Покажчики зібрані на Київщині, бо звідти йде «Місток». Вони ростуть разом із селами: коли з наступного куща відкривається нова справа чи новий том, його покажчик стає сюди. Що і коли додалося, записано в [`ZMINY.md`](../ZMINY.md).

Помилку в рядку можна виправити прямо тут: pull request або лист на pravky@mistok.wiki з номером справи й сторінки.
