# Дослідження: що ми виміряли, роблячи «Місток»

Тут журнал наших вимірів: що ми перевіряли, щоб тексти про села були точнішими, а робота дешевшою, і що з того вийшло. Кожен файл - одне дослідження: питання, як міряли, числа, висновок і межі. Негативні результати тут на рівних із позитивними, бо вони заощаджують стільки ж.

Для кого: для тих, хто пише історію сіл і родів за архівними джерелами разом із мовною моделлю, і для тих, хто будує подібні системи. Сайт «Місток» пише Claude: одні запуски моделі шукають джерела, інший пише сторінку, ще інші перевіряють її проти джерел, а людина читає й править за ними.
